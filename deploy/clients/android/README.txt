Sofia's Resto-Lounge - Android (الأجهزة اللوحية والهواتف)
==========================================================

لا يوجد ملف APK: التطبيق يُثبَّت من خادم المطعم عبر Chrome. التفاصيل والصور في START-HERE.html.

1. اتصل بشبكة Wi-Fi المطعم.
2. في Chrome افتح:  http://عنوان-الخادم/sofia-ca.crt   (يُنزَّل ملف الشهادة)
3. الإعدادات > الأمان والخصوصية > إعدادات أمان إضافية > التشفير وبيانات الاعتماد >
   تثبيت شهادة > شهادة CA > التثبيت على أي حال > اختر sofia-ca.crt
4. في Chrome افتح:  https://عنوان-الخادم   وسجّل الدخول.
5. القائمة (⋮) > تثبيت التطبيق.
6. سجّل الدخول مرة والخادم متصل؛ بعدها يعمل الجهاز دون اتصال.

English
-------
There is no APK: the app is installed from the restaurant server with Chrome (details in START-HERE.html).
1. Join the restaurant Wi-Fi.
2. Chrome: open http://SERVER-ADDRESS/sofia-ca.crt (downloads the certificate).
3. Settings > Security & privacy > More security settings > Encryption & credentials > Install a certificate >
   CA certificate > Install anyway > choose sofia-ca.crt
4. Chrome: open https://SERVER-ADDRESS and sign in.
5. Menu (⋮) > Install app.
6. Sign in once while the server is reachable; afterwards the device also works offline.
