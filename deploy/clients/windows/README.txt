Sofia's Resto-Lounge - staff PCs (Windows)        حواسيب الموظفين
==============================================================

1. Double-click Setup-Staff-PC.cmd (allow administrator rights).
2. Enter the server address shown by the server installer / Sofia Server Manager (e.g. 192.168.1.10).
3. Compare the certificate fingerprint with the one in Sofia Server Manager and type Y if it matches.
4. Use the "Sofia's Resto-Lounge" shortcut on the desktop. Sign in once while the server is reachable;
   afterwards the PC also works when the server or the internet is down.

بالعربية:
1. انقر مرتين على Setup-Staff-PC.cmd ووافق على صلاحيات المسؤول.
2. اكتب عنوان الخادم (مثل 192.168.1.10).
3. قارن بصمة الشهادة بالبصمة في Sofia Server Manager واكتب Y إذا تطابقت.
4. استخدم اختصار "Sofia's Resto-Lounge" على سطح المكتب، وسجّل الدخول مرة والخادم متصل.

Not yet tested on a real Windows machine - try on one PC first.
