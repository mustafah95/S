كيف يعمل النظام

يُثبَّت الخادم مرة واحدة على حاسوب Windows في المطعم، وعليه قاعدة البيانات PostgreSQL وكل البيانات. أما الأجهزة الأخرى (حاسوب الاستقبال، الأجهزة اللوحية Android، آيفون وآيباد) فتستخدم نفس التطبيق عبر المتصفح، وتثبّته على الشاشة الرئيسية ليفتح كتطبيق مستقل.

بعد أول تسجيل دخول، يستمر كل جهاز بالعمل حتى لو انقطع الخادم أو الإنترنت (حجوزات، ضيوف، ملاحظات، طاولات)، ثم يزامن التغييرات تلقائياً عند عودة الاتصال.
لا يوجد تطبيق منفصل في Google Play أو App Store: التطبيق يُثبَّت مباشرة من خادم المطعم، فيعمل نفسه على كل الأجهزة ويصله كل تحديث تلقائياً.

1تثبيت الخادم (حاسوب Windows)

المتطلبات: Windows 10 (إصدار 1809 أو أحدث) أو Windows 11 أو Windows Server 2019 فما فوق، 64-بت، ذاكرة 8 GB يُفضّل، 10 GB مساحة فارغة، اتصال إنترنت أثناء التثبيت، وعنوان IP ثابت للحاسوب (اطلب من فني الشبكة حجز العنوان في الراوتر).

  1. افتح المجلد 1-Server-Windows\SofiaSetup-{{VERSION}}-windows.
  2. انقر مرتين على Install-Sofia.cmd ووافق على صلاحيات المسؤول.
  3. انتظر حتى ينتهي (يثبّت Node.js وPostgreSQL تلقائياً إن لم يكونا موجودين — قد يستغرق عدة دقائق).
  4. في النهاية يعرض المثبّت ويجب تدوينها:
    • عنوان الأجهزة مثل https://192.168.1.10
    • رابط شهادة الأجهزة مثل http://192.168.1.10/sofia-ca.crt وبصمة الشهادة
    • رمز الإعداد الأول
  5. يُفتح المتصفح على معالج الإعداد: أدخل رمز الإعداد، ثم اسم المطعم والفرع وساعات العمل والصالات والطاولات، وأنشئ حساب المالك بكلمة سر قوية من اختيارك (لا توجد كلمة سر افتراضية).

على سطح المكتب ستجد Sofia Server Manager: حالة النظام، تشغيل وإيقاف، نسخ احتياطي واستعادة، السجلات، العنوان وبصمة الشهادة.

إذا ظهر تحذير «Windows protected your PC» اضغط «More info» ثم «Run anyway» — الملف غير موقّع بشهادة توقيع كود بعد.

2حواسيب الموظفين (Windows)

  1. انسخ المجلد 2-Staff-Windows-PC إلى الحاسوب وانقر مرتين على Setup-Staff-PC.cmd.
  2. اكتب عنوان الخادم (مثل 192.168.1.10).
  3. تظهر بصمة الشهادة: قارنها بالبصمة في Sofia Server Manager ثم اكتب Y إذا تطابقت.
  4. يُنشأ اختصار «Sofia's Resto-Lounge» على سطح المكتب وفي قائمة ابدأ ويُفتح التطبيق.
  5. سجّل الدخول مرة واحدة والخادم متصل — بعدها يعمل الحاسوب دون اتصال عند الحاجة.

بديل يدوي: ثبّت الشهادة يدوياً (افتح الملف ← Install Certificate ← Local Machine ← Trusted Root Certification Authorities)، ثم افتح العنوان في Edge ← القائمة ⋯ ← التطبيقات ← تثبيت هذا الموقع كتطبيق.

3الأجهزة اللوحية والهواتف Android

  1. اتصل بشبكة Wi-Fi المطعم.
  2. في متصفح Chrome افتح http://عنوان-الخادم/sofia-ca.crt — سيُنزَّل ملف الشهادة.
  3. افتح الإعدادات ← الأمان والخصوصية ← إعدادات أمان إضافية ← التشفير وبيانات الاعتماد ← تثبيت شهادة ← شهادة CA ← «التثبيت على أي حال» ← اختر الملف sofia-ca.crt. (تختلف الأسماء حسب الشركة المصنّعة؛ ابحث في الإعدادات عن كلمة «شهادة».)
  4. في Chrome افتح https://عنوان-الخادم وسجّل الدخول.
  5. من القائمة ⋮ اختر تثبيت التطبيق (أو «إضافة إلى الشاشة الرئيسية»).
  6. افتح صوفيا من الشاشة الرئيسية من الآن فصاعداً.

4آيفون وآيباد

  1. اتصل بشبكة Wi-Fi المطعم.
  2. في متصفح Safari تحديداً افتح http://عنوان-الخادم/sofia-ca.crt ← «سماح» ← تظهر رسالة «تم تنزيل ملف التعريف».
  3. الإعدادات ← عام ← إدارة VPN والجهاز ← اختر ملف التعريف ← تثبيت.
  4. الإعدادات ← عام ← حول ← إعدادات الثقة بالشهادات ← فعّل الثقة الكاملة للشهادة «Caddy Local Authority».
  5. في Safari افتح https://عنوان-الخادم وسجّل الدخول.
  6. زر المشاركة ← إضافة إلى الشاشة الرئيسية ← إضافة.

5الضيوف: صفحة الحجز والإشعارات

  • رابط الحجز لكل فرع: https://نطاق-المطعم/book/رمز-الفرع. رمز QR وكود الأداة (Widget) لموقع المطعم في الإعدادات ← الفروع.
  • حتى يصل الضيوف من الإنترنت يجب أن يكون للنظام عنوان عام بـ HTTPS (نطاق مثل book.example.com — خيار -HttpsMode Domain عند تثبيت الخادم، أو خادم سحابي من المجلد 5).
  • إشعارات الضيوف: فعّل «push» في الإعدادات ← الإشعارات؛ يضغط الضيف «تفعيل الإشعارات» في صفحة تأكيد حجزه. على آيفون يضيف الضيف الصفحة إلى الشاشة الرئيسية أولاً (iOS 16.4 أو أحدث).

العمل دون اتصال

  • يجب تسجيل الدخول مرة واحدة على كل جهاز والخادم متصل. بعدها يمكن فتح التطبيق دون اتصال لمدة 72 ساعة (قابلة للتعديل).
  • الحجز الذي يُنشأ دون اتصال يظهر برقم يبدأ بـ LOCAL-، ثم يحصل على رقمه النهائي SR-… بعد المزامنة.
  • إذا حُجزت الطاولة نفسها من جهاز آخر أثناء الانقطاع، لا يُحذف الحجز: يُعلَّم «يحتاج مراجعة» ويُنبَّه الموظفون.

لماذا لا يوجد ملف APK أو تطبيق في App Store؟

اخترنا التطبيق عبر المتصفح (PWA) لأنه نسخة واحدة تعمل على Windows وAndroid وآيفون، وتعمل دون اتصال، وتُحدَّث من مركز التحديثات دون إعادة تثبيت على كل جهاز. يمكن لاحقاً تغليفه كتطبيق Android (ملف APK بمفتاح توقيع خاص بالمطعم) أو تطبيق آيفون (يتطلب حاسوب Mac وحساب Apple Developer بـ 99 دولاراً سنوياً ومراجعة Apple).

ملاحظة: سكربتات Windows (تثبيت الخادم، Server Manager، تجهيز حواسيب الموظفين) لم تُجرَّب بعد على جهاز Windows حقيقي. جرّبها أولاً على حاسوب احتياطي، وأرسل ملف السجل إن ظهر خطأ (يظهر مساره في بداية التثبيت).

How it works

The server is installed once on a Windows PC in the restaurant; it holds the PostgreSQL database and all data. Every other device (reception PC, Android tablets, iPhone/iPad) uses the same app through the browser and installs it to the home screen, where it opens like a normal app.

After the first sign-in each device keeps working when the server or the internet is down (reservations, guests, notes, tables) and synchronises automatically when the connection returns.
There is no separate Google Play or App Store app: the app is installed directly from the restaurant's server, is the same on every device and receives every update automatically.

1Server (Windows PC)

Requirements: Windows 10 1809+, Windows 11 or Windows Server 2019+, 64-bit, 8 GB memory recommended, 10 GB free disk, internet during installation, and a fixed IP address for the PC (DHCP reservation in the router).

  1. Open 1-Server-Windows\SofiaSetup-{{VERSION}}-windows.
  2. Double-click Install-Sofia.cmd and allow administrator rights.
  3. Wait until it finishes (Node.js and PostgreSQL are installed automatically when missing; this can take several minutes).
  4. Write down what the installer shows at the end: the device address (e.g. https://192.168.1.10), the device certificate link (http://192.168.1.10/sofia-ca.crt) and its fingerprint, and the setup token.
  5. The browser opens the setup wizard: enter the token, the restaurant, branch, opening hours, areas and tables, and create the owner account with your own strong password (there is no default password).

Sofia Server Manager (desktop shortcut) shows status, starts/stops services, creates and restores backups, shows logs, the address and the certificate fingerprint.

If Windows shows "Windows protected your PC", click "More info" → "Run anyway" (the files are not code-signed yet).

2Staff PCs (Windows)

  1. Copy 2-Staff-Windows-PC to the PC and double-click Setup-Staff-PC.cmd.
  2. Enter the server address (e.g. 192.168.1.10).
  3. Compare the certificate fingerprint with the one in Sofia Server Manager and type Y if they match.
  4. A "Sofia's Resto-Lounge" shortcut is created on the desktop and in the Start menu, and the app opens.
  5. Sign in once while the server is reachable; afterwards the PC also works offline.

Manually: install the certificate (open the file → Install Certificate → Local Machine → Trusted Root Certification Authorities), then open the address in Edge → ⋯ menu → Apps → Install this site as an app.

3Android tablets and phones

  1. Connect to the restaurant Wi-Fi.
  2. In Chrome open http://SERVER-ADDRESS/sofia-ca.crt; the certificate file downloads.
  3. Settings → Security & privacy → More security settings → Encryption & credentials → Install a certificate → CA certificate → Install anyway → choose sofia-ca.crt. (Names differ by manufacturer; search Settings for "certificate".)
  4. In Chrome open https://SERVER-ADDRESS and sign in.
  5. ⋮ menu → Install app (or Add to Home screen).

4iPhone and iPad

  1. Connect to the restaurant Wi-Fi.
  2. In Safari open http://SERVER-ADDRESS/sofia-ca.crt → Allow → "Profile Downloaded".
  3. Settings → General → VPN & Device Management → the profile → Install.
  4. Settings → General → About → Certificate Trust Settings → enable full trust for "Caddy Local Authority".
  5. In Safari open https://SERVER-ADDRESS and sign in.
  6. Share → Add to Home Screen → Add.

5Guests: booking page and notifications

  • Booking link per branch: https://YOUR-DOMAIN/book/BRANCH-CODE; QR code and website widget code in Settings → Branches.
  • Guests on the internet need a public HTTPS address (a domain with -HttpsMode Domain, or a cloud server from folder 5).
  • Guest notifications: enable "push" in Settings → Notifications; guests tap "Turn on notifications" on their confirmation page (on iPhone they add the page to the Home Screen first, iOS 16.4+).

Working offline

  • Sign in once on each device while the server is reachable; afterwards the app opens offline for 72 hours (configurable).
  • Reservations made offline show a LOCAL- number until they sync and receive their SR-… number.
  • If the same table was booked by another device meanwhile, nothing is deleted: the booking is flagged for review and staff are notified.

Why no APK or App Store app?

The app is a Progressive Web App: one version for Windows, Android and iPhone that works offline and is updated by the Update Center without reinstalling on every device. It can later be wrapped as an Android app (APK signed with the restaurant's key) or an iOS app (requires a Mac, an Apple Developer account at US$99/year and Apple review).

The Windows scripts (server installer, Server Manager, staff PC setup) have not yet been run on a real Windows machine. Try them on a spare PC first and send the log file if something fails (its path is shown when the installation starts).
